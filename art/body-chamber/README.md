# Body chamber silhouette reference

Drop your generated **PNG** here. **Black figure on white** (like a typical generator export) works best — no editing required. The script greys/contrast-normalizes and traces automatically.

| File | Purpose |
|------|---------|
| `reference.png` | Your image-generator output (you add this) |
| `traced.svg` | Auto-generated by `node scripts/trace-body-silhouette-reference.js` |
| `sil-shell-path.txt` | Single SVG `d` string scaled to game viewBox |

## Quick steps (no Inkscape)

1. Save / copy your mobile image as **`reference.png`** in this folder.
2. From repo root (needs `npm install potrace jimp` once — see script header):
   ```bash
   node scripts/trace-body-silhouette-reference.js
   ```
3. Open a PR or paste `sil-shell-path.txt` in chat — an agent runs `sync` and wires `#sil-shell` into `index.html`.

The game keeps **click regions** on simplified parts; the **visible** outline can be your traced shell.
