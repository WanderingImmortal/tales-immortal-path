# Procedural lesser sects (prototype)

Headless seeded generator for **minor / school** cultivation organizations. Consumed by:

- `scripts/test-procedural-lesser-sects.js` (Node)
- `sandbox/lesser-sects/` (browser lab + `data.js` catalog)
- `procedural-lesser-sects.js` (game bridge → `G.world.lesserSects`)

Rebuild browser bundle after generator changes:

```bash
node scripts/bundle-lesser-sects-lab.js
```
