## Intent

Author spine for the nameless being in Void Prison / Little Heaven: who he is, when he rose, what he wants, why he cannot be killed cleanly, and how a Dao Manifestation coalition boxed him. Tone is **personal Completion interrupted**, not cartoon evil — sealing is disaster control.

## Design notes

### At a glance

| Field | Lock |
|-------|------|
| **Public name** | None — nameless by Temple policy |
| **Nature** | Pre-Seal path walker; last of a killed lineage of true-dao craft |
| **Want** | **Completion** — finish unfinished Work on **true Samsara** (just stepped on when caught) |
| **Tone** | Not evil for its own sake; collateral world damage forces the seal |
| **Power** | ~Half-Step **weight** on wrong track; lifespan inestimable |
| **Kill** | Ledger death does not finalize — true-cycle coherence |
| **Seal** | Void Seeker (then **Dao Manifestation**) + other DMs → Void Prison |
| **Now** | Contained; ascent frozen; Seeker later Immortal / outer void |

### Timeline

```text
Pre-Seal: walks path, mid-Work, small disciple circle
    ↓ Seal closes (no warning) — most of path dies (incompatible with new law)
Early heaven (LONG): hunt — survivors hunted; some disciples → sealed pins
    ↓ He steps onto true Samsara (early) — durable, not yet uncatchable
    ↓ Seeker (DM) + DM coalition builds Void Prison / Little Heaven
Early heaven → … → Dao Wars → Imperial Sky: Watch maintains; he stays boxed
```

Void Temple institutionalizes the lock. Binding is **older than Tian and the Dao Wars**.

### Motive

- **Original (pre-Seal):** finish the dao/work already underway (**Completion**).
- **Sovereignty / reclaim-from-Seal** bitterness only makes sense **after** law exists — optional flavor, not original path purpose.
- Advancing true Samsara under heaven **scars the board** (wrong cycles, counties that will not die/live properly) — enough to justify containment.

### Seal foresight

**None.** Sky closes cold. (Upgrade to rumors only if a later plot needs rushed breakthroughs.)

### Path fate

- Most of his path **die** at/after Seal (incompatibility).
- Survivors **hunted**.
- He keeps **a few disciples** (not a mass school).
- Some contemporaries become **sealed danger pins**; not all sealed ancients are his.
- Later “experiments” = remnant **copycats** after he is boxed — do not require him free.

## True vs shadow daos (cosmology lock)

Heaven did **not** invent the deep laws. Select fundamentals existed **first**; heaven never fully owned them — it teaches **shadow / imitation** curricula (impressive, hard, not reality-rewrite).

| Dao | Role |
|-----|------|
| **Wuji** (primordial) | **Reserved — special.** Not prisoner Work. Later may **bridge toward Chaos** (return-to-one → step off the pipe). Keep ≠ Chaos in prose until that pass. |
| **Yin-Yang, Spacetime, Samsara, Karma** | **True / shadow dual** — true faces reality-affecting; player ladder = shadows by default |
| **Five Phases** | Fundamental for **player element chorus**, but **world grammar** (how matter is typed), not the “locked true rewrite” club. No (or weakest) true/shadow split for v1 |

**Why no retcon of true wielders:** heaven published copies. Editing the clone curriculum cannot delete a process on the source. Cage; don’t pretend a stamp rewrote the true dao.

**Wuji vs Chaos (one line each):**

- **Wuji:** “All returns to one.” (still, reunify)
- **Chaos:** “Nothing is filed — I write the next file.” (volatile, rewrite)

Do **not** invent a second primordial dao.

**True Spacetime as prisoner Work — rejected:** full time-rip mastery would make capture unbelievable.

## Power system

Not Dao Manifestation on the nine-realm ladder.

```text
[ True Samsara — just stepped on ]
         ↓
[ Wrong-ledger body — kill table ≠ heaven’s ]
         ↓
[ Half-Step-class weight — contests many DMs; early enough to cage ]
```

| Topic | Lock |
|-------|------|
| **Long life** | True-cycle coherence; inestimable / not usefully aging on mortal clock |
| **Won’t stay dead** | Ledger kill (tribulation kill, karma verdict, qi/soul collapse heaven recognizes) fails to finalize; re-coheres |
| **Why caught** | **Early** on true Samsara — durable, not finished mastery; DM coalition + pocket before he became uncatchable |
| **Vs Seeker then** | Stronger than single DM Seeker; Seeker was **Dao Manifestation** at sealing |
| **Seeker later** | Can still Ascend to Immortal after (same arc shape as Sword Immortal) — Immortal when he leaves for outer void is fine |
| **Not Chaos path** | Separate unless owner merges later |

Shadow arts + arrays can **wound and isolate**; they cannot cleanly erase.

## Sealing beat

1. Long hunt; kills fail.
2. He steps onto true Samsara (early).
3. Seeker convenes other Dao Manifestation cultivators.
4. Coalition constructs / forces **Void Prison** pocket (spacetime/void craft + arrays — isolation, not DPS kill).
5. Prisoner names it **Little Heaven** (black humor).
6. Watch / Temple maintain forever; Seeker later seeks a true end beyond the firmament.
