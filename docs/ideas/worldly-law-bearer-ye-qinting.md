## Personality (draft)

- **Not** warm like **还生** *Huánshēng* Gu — **dry, precise**, odd hospitality (tea, silence, **no questions** first hour).
- **Curiosity** about **people erased from records** — helps **unpersons**, not heroes.
- **Dislikes** charter offices, bounty placards, **name-as-leverage** (parallel to Gu’s clan forging **枯荣** seals — different sin).
- **Humor:** flat jokes about **stamps and ink**.

## Background (draft)

- **Origin:** **Registry copyist** — not disciple glamour; literate mortal family pushed into **Threshold City** bureaucracy, then **qi** late via discarded manual in the archive basement.
- **Dao Wars:** Did **not** rot passes or hold lines — **Manifestation** came when a **purge** ordered **mass strike-offs** from ledgers (names = execution without blade). His law **answered**: *if the Registry lies, heaven’s copy should not stick.*
- **Hermit choice:** Took **abandoned relay tower** (empty ward — [`settlement-lore.md`](settlement-lore.md) taboo echo) — **neutral** because **no census** reaches the hollow correctly.
- **Relation to Gu:** **None required** — maybe traders whisper **笑朽** pass and **空籍塔** in one breath as “places to avoid,” no alliance.

## Law — Unposted Name (未籍道 *Wèi Jí Dào*)

**World rule:** *What is **not truly registered** cannot bind; what is **posted falsely** **unwrites** itself here.*

| | |
|--|--|
| **Tier** | **Lesser way** — specialist Manifestation |
| **Inside ward** | Announced technique **names** / **bounty titles** / **oath forms** tied to Registry fiction **slip** — not “anti-all magic,” **anti-paper** |
| **Fear** | Assassins with **posted warrants** lose **charter backup**; sect **formal challenges** misfire if **name fraud** |
| **Tags (combat)** | **Peel** (layer strip on forged buffs), **Dampen** on **ledger-linked** effects |
| **Weak when** | **Brute** fight with **no names** (beasts, thugs); battle **outside** tower ward |
| **Kindness** | **Hides** unregistered; **does not** forge new identities — only **silence** |

**Not esoteric:** mirrors real setting stack — **charter / Registry / mandate** ([`law-taxonomy.md`](law-taxonomy.md) horizontal law) vs **embodied** dao vertical layer.
