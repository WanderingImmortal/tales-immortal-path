## Intent

**未收兵大道** *Wèi Shōu Bīng Dà Dào* — **Unstand-Down Great Dao** — Manifestation that **refuses to treat the war as over**: formations **not dismissed**, **merit rolls still open**, **dead still on active duty** in the holder’s field.

**Feel:** **wrong paperwork**, **army ghosts**, **investigate the regiment** — not meta-story theatre.

**Distinct from:** Fate ledger ([`fate-fortune-grounding.md`](fate-fortune-grounding.md)) — **one man’s broken stand-down**, local bleed, **physical props** (cups, lists, teeth-pay custom).

## Rule sentence

*The array has **not** been dismissed.*

## Player-visible (lean)

| Symptom | What it means (fiction) |
|---------|-------------------------|
| **Corpses saluted** | In his field, the **dead still “hold the win”** — he bows **rank**, not morality |
| **Victory cups, chipped** | **Officers’ mess** loot; tea = **same toast** he’s repeated since one siege |
| **Tips in teeth** | **Dead-pay** custom — coin/stone **through the mouth** to someone on the **roll** |
| **Lists with wrong names** | **Merit / muster roll** **one line off** — fix the line (investigate) → he **moves on** |
| **Recent “win” feels thin** | Victories **near him** don’t **settle** — boons glitch, challengers **revive** grudges *(light hook)* |
| **Recent “loss” nags** | Old debts / rematches **stir** — not forced duel; **situation-thread** weight |
