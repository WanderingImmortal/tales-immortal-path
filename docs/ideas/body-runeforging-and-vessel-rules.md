## 1. Owner-approved — fundamental nature of Runeforging

**Realm idx 5** is the first step where the cultivator **establishes direct connections** to principles underlying **physical cultivation** (Body Dao purview — working cosmology).

Prior realms **cultivate and transform** the vessel. Runeforging lets that vessel **receive and express** those principles **on or in** the body.

| Principle | **Owner-approved** |
|-----------|-------------------|
| **Not symbolic only** | A rune is **not** a decorative tattoo or detachable enchantment |
| **Authentic connection** | Forging a rune establishes a **real** cultivated connection; the inscription is the **manifested** aspect of that connection — **inseparable** |
| **Imagery** | *As if* Body Dao **wrote** its principles onto skin, bone, or organs — **metaphor only**; Body Dao is **not** locked as conscious, sentient, or hand-picking cultivators |
| **No forgery** | Copying appearance **does not** reproduce the connection |
| **Amplification realm** | Runeforging **amplifies and elevates** capabilities **already developed** — PT cultivators already have extraordinary strength, endurance, movement, regeneration **before** first principle rune |
| **Meaningful jump** | First successful **principle** rune = **meaningful** power increase — **not** a negligible % shim |

Materials, body-art recipes, and filings in [`nine-realm-ladder.md`](nine-realm-ladder.md) remain valid **forge procedures** — this doc locks **what a rune means**, not only how it is made.

## 2. Owner-approved — the **Body Rune** (preferred name)

Use **Body Rune** — not **Origin Rune** — as working name for the **Runeforging breakthrough** inscription.

| Aspect | **Owner-approved** |
|--------|-------------------|
| **Role** | Initial **direct** connection to the **overarching** Body Dao |
| **Capacity** | Develops the body’s ability to **receive and sustain** inscriptions of **specific** Body Dao principles |
| **Prerequisite** | **Required** before forging subsequent (principle) runes |
| **Not a fifth principle** | Does **not** represent Strength, Endurance, Regeneration, Movement, or any other **individual** principle |
| **Not a combat spike** | Forging it does **not** grant a **large immediate** physical power boost by itself |
| **Cultivation** | May be **further cultivated** to deepen/expand **connection capacity** |

**Qualitative breakthrough:** A cultivator may enter Runeforging with a **profound** qualitative step (Body Dao **link** + **capacity**) while **combat power** surges mainly as **principle runes** succeed — analogous: soul arts need soul refinement before techniques; Body Dao inscriptions need **connection capacity**.

**Do not lock:** slot count, capacity formula, anatomical site of Body Rune, numerical breakthrough threshold.

**Gap vs older docs:** [`nine-realm-ladder.md`](nine-realm-ladder.md) § Runeforging describes majors/minors and forge load but **did not** name Body Rune — **this doc extends**, does not rename realms.

## 3. Owner-approved — foundational rune set (working)

Four **preferred** foundational principles (supersedes illustrative **Vitality** in [`body-realm-journey-and-vital-essence.md`](body-realm-journey-and-vital-essence.md) §4 — Vitality dropped due to overlap with Endurance + Regeneration):

| Rune (working) | Body Dao principle | Amplifies (design) |
|----------------|-------------------|---------------------|
| **Strength** | Physical **force** | Striking, gripping, lifting, exerting force |
| **Endurance** | Sustaining effort / **withstanding strain** | Stamina, exhaustion resistance, prolonged physical demand |
| **Regeneration** | Physical **restoration** | Recovery from damage, rebuilding structures |
| **Movement** | Bodily **motion** | Speed, acceleration, agility, balance, direction change — **Movement** preferred over separate Speed + Agility runes |

**Owner-approved nuances:**

- Set is **preferred working** four — **not** a claim that no other foundational principles can ever exist.
- **Foundational** = established, relatively well-understood Body Dao connections.
- **Accessible** to any sufficiently developed body cultivator with knowledge, resources, and **Body Dao connection capacity** — **not** bloodline-, sect-, physique-, or Vessel-Rule-gated.
- Foundational forms should be **recognisable and relatively consistent** across cultivators (same underlying principles).
- **Unique** runes may look **substantially different**.
- **Anatomical placement** for foundational runes: **unresolved** (skin, bone, organ possible).

## 4. Owner-approved — accessibility, one principle, completing the set

### One connection per principle

- **No** stacking multiple independent **Strength** runes for identical bonus.
- A rune = one cultivated **connection** to one principle.
- Progress = **breadth** (more principles) + **depth** (strengthen existing connection via further Runeforging).

**Do not implement** in design: duplicate stacking, arbitrary rune levels, numeric level curves.

### Completing the foundational set

| **Owner-approved** | |
|-------------------|--|
| **Not mandatory** to forge **all four** to advance to idx 6–8 | |
| **Full set + development** generally **superior overall achievement** vs partial set, **all else equal** | |
| Each added rune raises **capability floor** and opens more breadth/depth | |
| **Do not** artificially equalise partial vs complete sets | |
| Specialists can still win via deeper one connection, physique, Martial Intent, experience, prep | |
| Complete set = **prestigious**, high investment | |
| **No absolute requirement** to complete set for Source Furnace, Inner Source, or Saintly Flesh **without later owner approval** | |

## 5. Owner-approved — Vessel Rules & unique inscriptions

### Conceptual direction

| **Owner-approved** | |
|-------------------|--|
| Vessel Rules = possible path to **deep personal** Body Dao relationship | |
| **Not** “behaviour restriction → arbitrary numeric bonus” only | |
| Cultivator **embodies** a principle through conduct, cultivation, and physical existence | |
| **Adherence** (especially when breaking would be advantageous) deepens connection — **not** time alone | |
| **Breaking** may **destabilise** connection → backlash (weakened power, damaged rune, lost cultivation, severe betrayal outcomes — **severity unresolved**) | |
| Backlash = consequence of **contradicting cultivated Dao connection** — **not necessarily** conscious punishment by sentient Body Dao | |

### Relationship to runes

- Rules **may** yield **unique or deeply personalised** runes.
- Rule + Body Dao connection + manifested rune = **inseparable achievement** — rune is **not** a reward sticker for obedience.

### Preserved distinctions — **Owner-approved**

| Statement |
|-----------|
| Foundational runes **do not require** Vessel Rules |
| Vessel Rules **not mandatory** for all body cultivators |
| Not every unique rune requires a Rule; not every rune **is** a Rule |
| Vessel Rules **≠** Martial Intent ([`body-martial-intent.md`](body-martial-intent.md)) |
| Vessel Rules **not mandatory for sanctification** (see conflicts §8) |
| **Rule of Blood** and **Rule of the Unnamed** (player-facing catalog) **preserved** — player Da Chi ≠ catalog identity |

**Unresolved:** first realm at which a Rule may be sworn (code idx **2** vs lean idx **5–6**).

## 6. Owner-approved — Mad Arhat **Da Chi** & Rule of the Unnamed

**Canon for Da Chi (fiction):** apex Vessel Rule = **Rule of the Unnamed** — **not** the workshop **Rule of Unyielding** candidate in [`vessel-rules-design.md`](vessel-rules-design.md) / [`body-path-sect.md`](body-path-sect.md) (see §8).

### Revised Rule interpretation — **Owner-approved**

| Earlier sketch | **Locked direction** |
|----------------|---------------------|
| Relinquish named martial techniques for power on “ordinary” attacks | **Retained sacrifice**, reframed under Body Dao |
| — | Da Chi expresses **accumulated martial understanding** **through the cultivated body** — **the body is the technique** |
| Rule auto-grants mastery | **No** — mastery from cultivation, combat experience, **Martial Intent** |
| — | Rule establishes **profound Body Dao connection** so understanding flows through **ordinary physical actions** |

**Unresolved:** prohibited technique boundaries, specific powers, Rule progression stages for Da Chi.

**Personality:** **Owner-approved** — exuberant, boisterous, formidable; Rule does **not** require silence, modesty, or restrained personality.

### Da Chi’s unique rune — **Owner-approved**

| Property | Direction |
|----------|-----------|
| Tied to **Rule of the Unnamed** | Inseparable from Rule + connection |
| **Forged into sternum bone** — not skin tattoo only | Normally hidden under robes |
| **Not** enchantment, transferable ability, or power source separate from Rule |
| **Cannot** reproduce by copying appearance |
| **Unnamed** by Da Chi; others may describe descriptively; **no official rune name** locked |

**Thematic contrast — Owner-approved:** greatest cultivation achievement **hidden and unnamed** while his public persona is loud and forward.

### Sanctification — **Owner-approved**

- Unique rune + Rule = **major personal foundation** — **do not** alone explain Saintly Flesh.
- Saint status also from **physique, Inner Source**, accumulated cultivation.
- **No** mandatory link between unique Rule runes and achieving Saintly Flesh.
