## Intent

A **parked roster** of famous, infamous, and disputed people the jianghu might name-drop — in inn rumors, pamphlet epigraphs, elder lectures, or future chronicle entries. This is **not** a quest backlog and **not** canon until you copy a figure into a sect doc or promote them with an Issue.

**Feel:** xianxia “everyone has heard the story”; some names are true, some are propaganda, some are two people merged by time.

## Roster rules (keep it light)

1. **Tag every entry** with `canon` / `sketch` / `folklore` — folklore can be wrong on purpose.
2. **Prefer hooks over biography** — one wound, one boast, one thing peasants repeat wrong.
3. **Realm band, not spreadsheet** — e.g. “peak FE local king,” “Dao War elder,” “maybe Immortal.” Use [`nine-realm-ladder.md`](nine-realm-ladder.md) idx when you care; juniors in fiction still say old seven-realm slang.
4. **Zone or institution** — where the name travels (Redwell well-lane vs Heartlands charter schools).
5. **Optional game crumbs** — `rumorKey`, chronicle id, sect — leave blank until needed.

## Living or recent (Imperial Sky — ~3k years since Dao Wars)

### Bell-Mute Zhou · the Last Listener

| | |
|--|--|
| **Status** | `sketch` |
| **Era** | Early Imperial Sky |
| **Realm (public)** | Golden Core |
| **Realm (truth)** | Golden Core — never broke again |
| **Lane** | qi (formation-adjacent) |
| **Where heard** | Heartlands border inns; old cult-hunters |
| **Org tie** | none (claimed ex–Outer Demon cell) |

**One-line:** The man who survived the Great Withdrawal because he **stopped listening** the day the gorge went quiet.

**Story hook:** Says he traded his breakthrough for a name the heavens forgot — cultivators debate whether that is cowardice or the only real escape from Devouring Intent. Charter schools use him as a **warning parable**; one Lotus archive lists him as **fabricated**.

**What peasants get wrong:** That he was a **Half-Step** who chose mortality — he was GC at best.

**Owner notes:** Pairs with Draught/Withdrawal timeline when locked ([`lore-consistency-review-2026-09.md`](lore-consistency-review-2026-09.md)).

### Ironscar Situ · three-lung alchemist

| | |
|--|--|
| **Status** | `sketch` |
| **Era** | Imperial Sky (contemporary) |
| **Realm (public)** | peak QC / early FE |
| **Realm (truth)** | same |
| **Lane** | qi + Dustbone field lore |
| **Where heard** | Redwell, Ironscar dig crews, Well-Ring pamphlets |
| **Org tie** | freelance; refuses Well-Ring oath |

**One-line:** Brews from **scar-sand** and brags that Redwell’s well water is “polite” compared to Ironscar bleed.

**Story hook:** Not strong — **famous for recipes and stubbornness**. Players might only ever see his name on a pamphlet margin. Good template for **local renown** vs world legends.

**What peasants get wrong:** That the third lung is literal — it is a **metaphor** for a failed body-refining experiment he advertises as success.

**Owner notes:** Tie to [`dustbone-qc-alchemy.md`](dustbone-qc-alchemy.md) “who is famous for which.”

**One-line:** The official who kept **adding wards to the census** until the basin taught him what “one soul too many” means.
