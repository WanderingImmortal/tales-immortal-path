# Ram (scratch — not canon)

**Raw brainstorms.** Paste half-formed mechanics, other-AI passes, and “what if” without treating this as design truth.

| Layer | Where | When |
|-------|--------|------|
| **Ram** | `docs/ram/` | Throw ideas, iterate in chat, dump here |
| **Design** | `docs/ideas/<topic>.md` | Solid enough to build against (`_template.md`) |
| **Build** | GitHub Issue | Next implementable chunk |

## Rules

- **Status here:** always informal — no `designed` / `shipped` labels required.
- **Do not** merge ram wording into player-facing copy or code without promoting.
- **Promote** when an idea has intent + enough mechanics: copy the good bits into `docs/ideas/<kebab>.md`, link back to ram entry date, add a row to `docs/ideas/README.md` if it’s a new topic.
- **Drop** by striking through or one-line “dropped because …” — keep history, don’t delete threads unless noise.

## Files

| File | Use |
|------|-----|
| [`inbox.md`](inbox.md) | Default dump — chronological sections per session |

Add topic-specific ram files only if `inbox.md` gets unwieldy (e.g. `dao-laws-ram.md`).
