### Combat tempo — AP vs time cost (owner dump)

**Problem to solve:** In fights with **movement**, **attacks**, and **quick defends** against a **telegraphed big hit**, something has to budget *when* you can do each — otherwise it’s all or nothing per turn.

**Owner lean (either/or, not decided):**

| Option | Sketch | Pros / cons (ram) |
|--------|--------|-------------------|
| **AP pool** | Spend points per action type (move = 1, light attack = 1, brace/parry = 1, heavy = 2…) | Readable; combo turns; risk of “always optimal script” |
| **Time cost** | Each action advances **your** clock / delays next readiness by N beats | Same spine as ATB windup; heavy defend might cost less *now* but push you late |
| **Hybrid** | ATB tick + small AP cap per “beat” when bar fills | Matches “one moment, several micro-choices” |
