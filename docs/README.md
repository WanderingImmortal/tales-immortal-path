# Project docs

## Work tracking (hybrid)

| Layer | Answers | Location |
|-------|---------|----------|
| **Now** | What am I focusing on? | [`NOW.md`](NOW.md) |
| **Owning topic notes** | What was intended, decided, and completed within a stated scope? | [`ideas/`](ideas/) |
| **Idea index** | Where is the owning note? Existing labels are navigation cues. | [`ideas/README.md`](ideas/README.md) |
| **Queue** | Actionable build work | [GitHub Issues](https://github.com/WanderingImmortal/tales-immortal-path/issues) |
| **PR history** | What landed, and what evidence accompanied it? | Merged PRs |
| **Production code** | What behaviour can the game reach today? | Production entry points and dependencies |
| **Tests** | What behaviour was demonstrated, and under which conditions? | Relevant tests and verification results |

**Rule of thumb:** rich design → `docs/ideas/`; ready to implement (or a clear prerequisite chunk) → open an Issue and link both ways.

Use [system reconciliation](system-reconciliation.md) to compare those sources for a specific gameplay slice.
